CROSS-CUTTING GRADING / SYSTEM DESIGN FINDINGS</h1><h2>9.1 Source-of-truth / version-control defect</h2><p>EMR data, standardized-patient responses, grading reference, answer key, and clinical decision pathway should share an explicit case/version identifier. The repeated cross-patient contradictions strongly suggest that multiple components may be referencing different versions of the same scenario.</p><h2>9.2 Hidden-data grading</h2><p>If a fact is required for points, it should be visible in the student-facing EMR, available through the standardized-patient interview, or clearly obtainable through an authorized preceptor/chart request. Hidden values should not be required for full credit.</p><h2>9.3 Unknown/not assessed should be a valid state</h2><p>When the patient cannot answer a question or the chart does not provide the information, the system should support 'unknown,' 'not assessed,' or 'not available' rather than forcing the learner to invent a value.</p><h2>9.4 Clinical accuracy should outrank reference-string matching</h2><p>A SOAP note that accurately reflects the patient-facing case should not be marked incorrect because a hidden reference contains a different patient scenario.</p><h2>9.5 Objective data should be centralized</h2><p>Vitals, labs, PFTs, medication lists, allergies, histories, and scores should be stored once in an authoritative case object and consumed by the EMR, patient script, grading rubric, and clinical pathway.</p><h2>9.6 Patient goals should be patient-derived</h2><p>The grading key should not require a patient goal or concern that the patient did not express. If a specific goal is pedagogically required, the interview should explicitly ask it.</p><h2>9.7 Standardized scores should be accessible</h2><p>ACT/CAT scores should either be displayed in the EMR, explicitly obtainable from the preceptor/chart, or administered in the workflow. Students should not be expected to infer numeric scores.</p><h2>9.8 Clinical pathways must use the same inputs as grading</h2><p>For Bob, the EMR describes well-controlled COPD on LAMA while the reference expects escalation based on different exacerbation/eosinophil/CAT data. The treatment engine and grader should consume the same case data.</p><h1>10.
